Physician referral data, built from what CMS publishes.

Referral relationships follow structure: clinicians in the same group, at the same hospital, in the same ACO or at the same practice address refer to each other most. Stethos maps that structure for every US clinician from public CMS files, so your agent can find the specialists a primary care group is likely to send patients to, and the reverse.

FAQ

Physician referral data: common questions

Related: Docs: data sources · Physician data API · Medtech and pharma

Does CMS publish referral data?

CMS released Physician Shared Patient Patterns files in response to FOIA requests, but they cover claims only through 2015. For current relationships, Stethos uses group, hospital, ACO and location data that CMS updates regularly.

Will Stethos have claims-based referral flows?

That's the plan. Current referral counts between clinicians require claims-level Medicare data from CMS's Virtual Research Data Center. Stethos plans to apply as an Innovator; only aggregate, privacy-protected counts can leave that environment.

Is this enough for sales targeting?

Often, yes. Shared groups, hospitals and ACOs explain most referral patterns, and they change faster than annual claims files. Stethos also tells your agent when an affiliation changes.

Is there patient data?

No. Stethos holds data about clinicians and organizations only.
