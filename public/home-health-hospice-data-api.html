Example call

One request, sourced answers.

Your agent can make the same call as an MCP tool. Every result carries the source and last-verified date on each field and the credits it used. See the quickstart and pricing.

curl https://api.stethos.health/v1/orgs/search \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{
  "type": "home_health_agency",
  "state": "GA",
  "fields": [
    "utilization",
    "star_rating",
    "ownership"
  ],
  "limit": 25
}'

FAQ

Home health and hospice data API: common questions

Related: Docs: data sources · Health system data API · Provider directories

How is this different from Trella Health or similar platforms?

Those platforms are built on claims-level Medicare data and sold as annual subscriptions with dashboards. Stethos starts from CMS's public files, priced per tool call and built for agents through MCP. Claims-level referral flows are planned, through CMS's research data program.

How current is it?

Star ratings and quality measures refresh monthly to quarterly. The utilization files are released yearly. Every field shows its source and date.

Can I see referral sources and destinations?

Not yet. Which hospitals and physicians send patients to which agencies requires claims-level data from CMS's Virtual Research Data Center, which Stethos plans to apply for. Today you get each provider's volume, mix, quality and ownership.

Does it include patient data?

No. Everything is aggregated to the provider, and CMS suppresses small counts.
