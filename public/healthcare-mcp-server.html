Example call

One request, sourced answers.

Your agent can make the same call as an MCP tool. Every result carries the source and last-verified date on each field and the credits it used. See the quickstart and pricing.

curl https://api.stethos.health/v1/providers/search \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{
  "specialty": "dermatology",
  "city": "Austin",
  "state": "TX",
  "limit": 10
}'

FAQ

Healthcare MCP server: common questions

Related: Docs: connect in five minutes · NPI lookup API · Pricing

How is this different from free NPI MCP servers?

Free servers wrap the public NPI registry. Stethos starts from the same NPI and adds state licenses, current affiliations, payer networks and organization data, with a source on every field and alerts when a record changes.

Do I need to talk to sales?

No. It's self-serve: 1,000 free credits, no card, and plans and top-ups you can manage yourself.

Does it handle patient data?

No. Stethos only holds data about clinicians and organizations, so there's no PHI and no business associate agreement needed.

What does it cost?

Each tool call costs credits: a search result is 0.05, a provider record is 1 plus optional fields. Build is $149 a month for 20,000 credits.
