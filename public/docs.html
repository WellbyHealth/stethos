Authenticate

Every request takes your API key as a bearer token. Keys are created per project in the dashboard.

export STETHOS_KEY="sk_live_..."
curl https://api.stethos.health/v1/account \
  -H "Authorization: Bearer $STETHOS_KEY"

Search providers

Search returns lightweight matches at 0.05 credits per result. Filter by specialty, state, city, license_state, affiliation_type, org_id or network.

curl https://api.stethos.health/v1/providers/search \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{"specialty": "orthopedic surgery", "state": "AZ", "limit": 50}'

Enrich a provider

Pass an npi, or a name plus city and state. The base record costs 1 credit; each extra field group adds to it, so ask only for what you need.

curl https://api.stethos.health/v1/providers/enrich \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{"npi": "1234567890", "fields": ["licenses", "practice_contact"]}'

Every field comes back with a source and a verified date. When sources disagree, the response includes alternatives so you can choose.

Organizations

Look up health systems, hospitals, groups and clinics by name, org_id or NPI. Records include locations, child organizations, rostered clinicians, leadership and open clinical roles.

curl https://api.stethos.health/v1/orgs/enrich \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{"name": "Example Health System", "state": "AZ"}'

Watchers and webhooks

A watcher follows a set of NPIs or organizations and posts an event to your webhook when something changes. Each delivered event costs 0.5 credits.

EventFires when
affiliation.changedA clinician joins or leaves a group, hospital or system
license.issued · license.lapsedA state license is added, expires or is restricted
network.joined · network.leftA listing appears in or drops from a payer directory
location.openedA new practice site or clinic is seen
org.exec_hireAn organization names a new executive
org.hiring_spikeClinical job posts rise well above normal
curl https://api.stethos.health/v1/watchers \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{"npis": ["1234567890"], "events": ["affiliation.changed"],
       "webhook_url": "https://your-app.example/hooks/stethos"}'

Webhooks are signed with your project secret in the Stethos-Signature header. Failed deliveries retry with backoff for 24 hours.

MCP server

Agents in Claude and other MCP clients can use Stethos as tools: search_providers, enrich_provider, enrich_org and recent_changes. Add the server URL and your key in your client's connector settings.

https://mcp.stethos.health/v1   # Authorization: Bearer $STETHOS_KEY

Credits

Every response includes an X-Credits-Used header, and GET /v1/account/credits returns your balance for free. See pricing for the cost of each call.

Errors and limits

StatusMeaning
401Missing or invalid API key
402Out of credits. Nothing was charged.
404No record found. Nothing was charged.
429Rate limit: 600 requests a minute on Build. Retry after the Retry-After header.
