Home / License data API

Medical license lookups across every state, in one call.

Every state runs its own licensing boards, each with its own website and format. Stethos is built to gather license records from state boards into one NPI-keyed record, show each license's status and source, and alert you when one changes.

License data API

Look up

  • All licenses for an NPI
  • Clinicians licensed in a given state
  • Recent license events by state and profession

For each license

  • State, profession and license number
  • Status: active, expired, restricted
  • Issue and expiration dates where published
  • Source board and verified date

Example call

One request, sourced answers.

Your agent can make the same call as an MCP tool. Every result carries the source and last-verified date on each field and the credits it used. See the quickstart and pricing.

curl https://api.stethos.health/v1/providers/enrich \
  -H "Authorization: Bearer $STETHOS_KEY" \
  -d '{
  "npi": "1234567890",
  "fields": [
    "licenses"
  ]
}'

FAQ

License data API: common questions

Related: Clinical staffing and recruiting · Docs: watchers · Physician data API

Is this primary source verification?

No. Stethos is not a credentials verification organization. It's built for sourcing, prospecting, directory checks and monitoring. For credentialing, verify with the state board or your verification vendor.

Which professions are covered?

Physicians first, then nurses and other licensed clinicians. Coverage will be published by state and profession at launch.

Can I be told when a license lapses?

Yes. Watchers fire license.lapsed and license.issued events for the clinicians you follow.
